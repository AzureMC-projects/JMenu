# Changelog

All notable changes to JMenu are documented here.

## v1.0.1 - 2026-10-11

- Fixed the menu hotkey to use Geode's `KEY_GraveAccent` key code for backtick.
- Replaced the log-only menu toggle with a visible Geode-native menu alert.
- Updated the mod ID, developer label, description, source, and issue tracker metadata.
- Clarified Safe Mode limitations and the status of planned gameplay tools.
- Documented the official Geode submission checklist and CBF integration.

## v1.0.0 - Initial scaffold

- Added the initial Geode project, hack registry, Safe Mode setting, and GitHub Actions build workflow.
- Added a suggested dependency entry for Click Between Frames.
- Added initial registry entries for Speedhack, Noclip P1, and Show Layout. These entries do not by themselves implement gameplay hooks.
